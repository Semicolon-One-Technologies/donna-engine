# Donna

Donna 是用于构建和部署对话式语音智能体的平台。

> 专有声明: Donna 是 Semicolon One Technologies 的专有工具。保留所有权利。版权严格执行。

## 快速开始

1. 克隆本仓库。
2. 在仓库根目录使用 Docker Compose 启动服务。
3. 打开 http://localhost:3010 并创建第一个语音智能体。

## 产品链接

- 官网: https://speaktodonna.com
- 客户门户: https://portal.speaktodonna.com

## 核心能力

- 拖拽式工作流构建语音智能体
- 电信集成与实时语音编排
- 可灵活接入 LLM、TTS、STT
- 支持本地和自主管理部署

## SDK

- Python SDK: `sdk/python/`
- TypeScript SDK: `sdk/typescript/`
