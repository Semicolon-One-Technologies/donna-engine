# Security Policy

Donna is a proprietary product by Semicolon One Technologies.
If you have found a security issue, please report it through Semicolon One Technologies official channels.

## Supported Versions
We always recommend using the latest versions of services to ensure you get all security updates

## Reporting a Vulnerability

If you believe you have found a security vulnerability within Donna, please let us know right away. We'll try to fix the problem as soon as possible.

Do not report vulnerabilities in public forums.

Once we receive your report, we'll keep you updated as we fix the vulnerability.

## Thanks

Thank you for helping keep Donna and its users safe.
